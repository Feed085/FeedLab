# 1. LAYİHƏNİN ÜMUMİ TƏSVİRİ

## 1.1. Feed Lab nədir?

Feed Lab, FEED Agency tərəfindən yaradılacaq rəqəmsal layihə marketplace platformasıdır.

Platformanın əsas məqsədi elektronika, proqramlaşdırma, IoT və mühəndislik sahələrində hazırlanmış layihələri vahid mərkəzdə toplamaq, müəlliflərə öz layihələrini satışa çıxarmaq, istifadəçilərə isə bu layihələri əldə etmək imkanı yaratmaqdır.

Feed Lab sadəcə fayl satış platforması olmayacaq. Burada müəllif profilləri, layihə portfolioları, istifadəçi rəyləri, texniki dəstək, müəllif müraciətləri, loyallıq sistemi və icma funksiyaları da olacaq.

Platforma FEED Agency ekosisteminin ayrıca məhsulu kimi fəaliyyət göstərəcək.

## 1.2. Əsas konsepsiya

Feed Lab üç əsas iştirakçı qrupunu birləşdirir:

- Layihə hazırlayan müəlliflər.
- Hazır layihələri əldə edən istifadəçilər.
- Marketplace-i idarə edən FEED Agency komandası.

Müəllif öz layihəsini platformaya təqdim edir. Admin layihəni yoxlayır və təsdiqləyir. Təsdiqlənmiş layihə satışa çıxarılır. İstifadəçi layihəni satın alır və şəxsi istifadə lisenziyası çərçivəsində fayllara giriş əldə edir.

## 1.3. Platformanın əsas istiqaməti

İlk mərhələdə yalnız elektronika və IoT sahəsinə fokuslanılır.

Platformanın gələcəkdə digər texnologiya və proqramlaşdırma kateqoriyalarına genişlənməsi mümkündür.

# 41. BÜTÜN TEXNİKİ SUALLAR VƏ CAVABLAR

Bu bölmədə texniki stack seçimi zamanı verilən suallar və istifadəçinin təsdiqlədiyi cavablar qeyd olunur.

## TQ1. Backend texnologiyası nə olacaq?

**Cavab:** NestJS.

Backend NestJS üzərində qurulacaq.

## TQ2. Database texnologiyası nə olacaq?

**Cavab:** MongoDB.

Platformanın əsas database-i MongoDB olacaq.

## TQ3. MongoDB inteqrasiyası üçün hansı texnologiyadan istifadə ediləcək?

**Cavab:** Mongoose.

NestJS və MongoDB arasında Mongoose istifadə olunacaq.

## TQ4. Frontend texnologiyası nə olacaq?

**Cavab:** React.

Frontend React ilə hazırlanacaq.

## TQ5. UI/CSS texnologiyası nə olacaq?

**Cavab:** Tailwind CSS.

Responsive və fərdiləşdirilə bilən interfeys üçün Tailwind CSS istifadə olunacaq.

## TQ6. Frontend komponent kitabxanası nə olacaq?

**Cavab:** shadcn/ui.

Tailwind CSS ilə birlikdə shadcn/ui istifadə olunacaq.

## TQ7. Frontend Routing texnologiyası nə olacaq?

**Cavab:** React Router.

Marketplace, istifadəçi paneli, müəllif paneli və admin panelinin marşrutları React Router ilə idarə olunacaq.

## TQ8. State Management və Data Fetching necə olacaq?

**Cavab:** TanStack.

TanStack seçilib. TanStack Query server məlumatları, cache və API sorğularının idarə olunması üçün nəzərdə tutulur. Zustand əlavə olaraq təklif edilib, lakin ayrıca təsdiqlənməyib.

## TQ9. Form Validation texnologiyası nə olacaq?

**Cavab:** React Hook Form + Zod.

Formların idarə olunması və məlumat yoxlaması üçün istifadə ediləcək.

## TQ10. Authentication sistemi necə qurulacaq?

**Cavab:** Custom Authentication.

Autentifikasiya NestJS backend daxilində qurulacaq. Google OAuth, JWT, refresh token, e-mail verification və 2FA nəzərdə tutulur.

## TQ11. API Communication necə olacaq?

**Cavab:** REST API.

Frontend və backend REST API vasitəsilə əlaqə saxlayacaq.

## TQ12. API Documentation üçün hansı texnologiya istifadə ediləcək?

**Status:** Hələ təsdiqlənməyib.

Təklif olunan seçimlər:

- Swagger / OpenAPI.
- Postman.
- Swagger + Postman.

Tövsiyə: Swagger + Postman.
